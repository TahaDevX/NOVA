NOVA - Intelligent Desktop Assistant
Developed by Muhammad Taha Torabzadeh (GitHub: TahaDevX, Email: MohammadTaha.dev@gmail.com).

Install: run install.bat, configure .env, then run start.bat.
At startup, NOVA opens a phone connection page with QR codes. Scan a code or enter the displayed address on a phone connected to the same Wi-Fi network.
